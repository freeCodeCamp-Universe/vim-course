# --author-notes--

## CAG

**Concept:**
A number placed before a motion or operator repeats it that many times — `5j` moves down 5 lines, `3dd` deletes 3 lines. The same mechanic, applied to movement and to editing.

**Activity:**
Use a count with a motion to move a precise distance, then a count with `dd` to delete a precise number of lines.

**Goal:**
The learner repeats a motion or an editing command a precise number of times in one command, instead of pressing it repeatedly.
